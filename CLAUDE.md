# CLAUDE.md — Frontend

Notes for AI assistants (Claude, Copilot, etc.) working in this repo.

## Posters & infographics

Requests for a poster, infographic, announcement or maintenance notice: follow
[`docs/POSTERS.md`](docs/POSTERS.md). Start from the closest template in
`tools/posters/templates/`, render with `node tools/posters/render.js <name>`, and
run its checklist (facts from the module docs, no text off the edge, QR codes scan).
